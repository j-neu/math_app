# Skill A3.3

**Skill ID:** A3.3

**Construct:** A3.3

**Domain:** A

**Title DE:** Zahlbeziehungen nutzen

**Title EN:** Using number relationships

**Description DE:** Das Kind verbindet Zahlen über Verdopplungen, Halbierungen und Nachbarzahlen miteinander. Aus bekannten Beziehungen leitet es unbekannte Ergebnisse ab und verankert Zahlen in einem Netz aus Zusammenhängen.

**Description EN:** The child connects numbers through doubles, halves and neighbouring numbers. From known relationships it derives unknown results and anchors numbers in a network of connections.

**Color:** amber

**Basis:** Gaidoschik 2010; Padberg & Benz 2021. Eigene Ableitung: Zahlbeziehungen machen Rechenaufgaben an Bekanntes anschlussfähig statt jede Aufgabe isoliert zu lösen.
