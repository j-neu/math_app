# Skill A3.2

**Skill ID:** A3.2

**Construct:** A3.2

**Domain:** A

**Title DE:** Zerlegungen einer Zahl finden

**Title EN:** Finding decompositions of a number

**Description DE:** Das Kind findet zu einer Zahl mehrere unterschiedliche Zerlegungen und wechselt sicher zwischen verschiedenen Zusammensetzungen derselben Zahl. Dabei nutzt es die Einsicht, dass eine Zahl auf viele Arten in Teile geteilt werden kann.

**Description EN:** The child finds several different decompositions of a number and moves confidently between various combinations of the same number. It draws on the insight that a number can be split into parts in many ways.

**Color:** amber

**Basis:** Karner, Zahlzerlegungen im ZR10 (OA); Padberg & Benz 2021. Eigene Ableitung: Flexible Zerlegung ermöglicht die Wahl günstiger Zwischenschritte beim Rechnen.
