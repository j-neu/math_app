# Skill D1.2

**Skill ID:** D1.2

**Construct:** D1.2

**Domain:** D

**Title DE:** Die passende Rechenoperation erkennen

**Title EN:** Recognizing the required operation

**Description DE:** Das Kind erkennt in einer Sachsituation, welche Rechenoperation gefordert ist, und führt die zugehörige Rechnung aus. Es begründet die Wahl der Operation mit der Situation.

**Description EN:** The child recognizes which operation a story situation requires and carries out the corresponding calculation. It justifies the choice of operation by the situation.

**Color:** violet

**Basis:** Padberg & Benz 2021; Rahmenlehrplan BE/BB 2023. Eigene Ableitung: Das Erkennen der Operation ist der abschließende Schritt der Übersetzung von Kontext in Rechnung.
