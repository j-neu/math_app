# Skill C2.3

**Skill ID:** C2.3

**Construct:** C2.3

**Domain:** C

**Title DE:** Subtrahieren durch Ergänzen

**Title EN:** Subtracting by adding on

**Description DE:** Das Kind löst Subtraktionsaufgaben mit Zehnerübergang, indem es von der kleineren Zahl aus bis zum Ergebnis ergänzt. Es verzichtet dabei auf das mühsame rückwärts Zählen.

**Description EN:** The child solves subtraction tasks across a ten by adding on from the smaller number to reach the result. It avoids laborious counting backward.

**Color:** emerald

**Basis:** Selter/Spiegel 1997; Gaidoschik 2010. Eigene Ableitung: Ergänzen nutzt die Umkehroperation und ist schneller und sicherer als rückwärts Zählen.
