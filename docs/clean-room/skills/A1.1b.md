# Skill A1.1b

**Skill ID:** A1.1b

**Construct:** A1.1

**Domain:** A

**Title DE:** Vorwärtszählen bis 100

**Title EN:** Counting forward to 100

**Description DE:** Das Kind setzt das Vorwärtszählen von beliebigen Startpunkten über die Zehnergrenzen hinweg bis in den Hunderterraum fort. Die Zahlenfolge bleibt dabei auch über mehrere Stellenwechsel hinweg stabil.

**Description EN:** The child continues counting forward from any starting point across the tens boundaries up to one hundred. The sequence stays stable even across several place-value changes.

**Color:** amber

**Basis:** Padberg & Benz 2021; KMK 2022. Eigene Ableitung: Der Hunderterraum fordert das Überschreiten mehrerer Zehnergrenzen und bildet den Übergang zur schriftlichen Zahldarstellung.
