# Skill A1.2b

**Skill ID:** A1.2b

**Construct:** A1.2

**Domain:** A

**Title DE:** Rückwärtszählen bis 100

**Title EN:** Counting backward to 100

**Description DE:** Das Kind zählt von Startpunkten im Hunderterraum aus rückwärts und überschreitet dabei die Zehnergrenzen korrekt. Die absteigende Folge gelingt auch über mehrere Stellenwechsel hinweg ohne Abweichung.

**Description EN:** The child counts backward from starting points in the hundreds range, crossing the tens boundaries correctly. The descending sequence stays correct even across several place-value changes.

**Color:** amber

**Basis:** Wartha 2019; Padberg & Benz 2021. Eigene Ableitung: Rückwärtszählen über Dekadengrenzen hinweg stützt später das Subtrahieren ohne Nachbaraufgaben.
