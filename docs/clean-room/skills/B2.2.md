# Skill B2.2

**Skill ID:** B2.2

**Construct:** B2.2

**Domain:** B

**Title DE:** Zahlen am Zahlenstrahl verorten

**Title EN:** Placing numbers on the number line

**Description DE:** Das Kind trägt Zahlen auf dem Zahlenstrahl ein und entnimmt ihnen ihre Lage im Zahlenraum. Es nutzt den Strahl als strukturiertes Modell, um Abstände und Anordnungen von Zahlen abzulesen.

**Description EN:** The child places numbers on the number line and reads off their position in the number range. It uses the line as a structured model to read distances and the order of numbers.

**Color:** indigo

**Basis:** Schipper 2009; KMK 2022. Eigene Ableitung: Der Zahlenstrahl verknüpft Zahlorientierung mit der Vorstellung von Abständen zwischen Zahlen.
