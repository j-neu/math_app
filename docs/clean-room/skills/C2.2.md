# Skill C2.2

**Skill ID:** C2.2

**Construct:** C2.2

**Domain:** C

**Title DE:** Verdopplungen als Stützaufgaben nutzen

**Title EN:** Using doubles as anchor tasks

**Description DE:** Das Kind nutzt bekannte Verdopplungen und Halbierungen als Stützpunkte für Aufgaben mit Zehnerübergang. Von der Verdopplungsaufgabe aus leitet es das Ergebnis der Nachbaraufgabe sicher ab.

**Description EN:** The child uses known doubles and halves as anchor points for tasks that cross a ten. From the double it derives the result of the neighbouring task reliably.

**Color:** emerald

**Basis:** Padberg & Benz 2021; Gaidoschik 2010. Eigene Ableitung: Stützaufgaben führen über einen bekannten Anker zur Lösung der Übergangsaufgabe.
