# Skill B1.1

**Skill ID:** B1.1

**Construct:** B1.1

**Domain:** B

**Title DE:** Zehner und Einer erkennen

**Title EN:** Recognizing tens and ones

**Description DE:** Das Kind erkennt in einer zweistelligen Zahl die Zehner und die Einer und benennt ihre Anzahl. Es verbindet die geschriebene Zahl sicher mit ihrer Zusammensetzung aus Zehner- und Eineranteil.

**Description EN:** The child recognizes the tens and the ones in a two-digit number and names how many there are. It reliably links the written number to its composition of tens and ones.

**Color:** indigo

**Basis:** Wartha 2019; Moser Opitz 2013. Eigene Ableitung: Das Zerlegen zweistelliger Zahlen in Zehner und Einer ist die tragende Stellewertvorstellung.
