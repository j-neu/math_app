## Rulings (disagreements / deviations)

1. **C3.1b `borrow_error` label (finding 5).** The controller-suggested label "beim Abziehen den Zehner nicht geöffnet" implies a borrow step that C3.1b explicitly never needs (provenance "kein Borge-Schritt"; new `column_constraint:"no_borrow"`). Used `"unnötig einen Zehner geöffnet"` instead — still the controller's code `borrow_error`, still construct-specific.
2. **P2 §5 `near_double` semantics (finding 9).** The P2 rule text "two boxes equal n, third box n±1" contradicts its own example 7+8 = 7+7+1 (1 ≠ 7±1). Corrected the contract to "two boxes equal n, third box is 1" (odd total n+n+1), which is what the spec's `box_labels:["Verdopplung","Verdopplung","1 dazu"]` and the construct require.
3. **C3.1b `op` rejected by check_specs.py (finding 3).** The committed validator already whitelisted `op` for `stellenwerttafel_read` (with `+|-`); the "strict check_specs.py rejects the spec" claim was stale. The real gap was the §4.5 vocabulary; closed it there and narrowed the validator enum to exactly `{"+","-"}` per the controller instruction.
