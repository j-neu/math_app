# Skill C3.3

**Skill ID:** C3.3

**Construct:** C3.3

**Domain:** C

**Title DE:** Mit Hilfsaufgaben rechnen

**Title EN:** Calculating with supporting tasks

**Description DE:** Das Kind nutzt bekannte Nachbar- und Ergänzungsaufgaben, um schwierige Aufgaben im Hunderterraum zu stützen. Vom Ergebnis der Hilfsaufgabe gelangt es über eine kleine Korrektur zum gesuchten Ergebnis.

**Description EN:** The child uses known neighbour and complement tasks to support difficult calculations in the hundreds range. From the supporting task's result it reaches the answer through a small correction.

**Color:** emerald

**Basis:** Padberg & Benz 2021; Selter/Spiegel 1997. Eigene Ableitung: Hilfsaufgaben verknüpfen neue Aufgaben mit bereits gesicherten Zahlfakten.
