# Skill C4.2

**Skill ID:** C4.2

**Construct:** C4.2

**Domain:** C

**Title DE:** Umkehraufgaben zur Kontrolle nutzen

**Title EN:** Using inverse tasks for checking

**Description DE:** Das Kind nutzt die Umkehrbeziehung von Addition und Subtraktion, um Aufgaben zu vereinfachen oder Ergebnisse zu prüfen. Aus einer Plusaufgabe bildet es die zugehörige Minusaufgabe und umgekehrt.

**Description EN:** The child uses the inverse relationship of addition and subtraction to simplify tasks or check results. From an addition it forms the matching subtraction and vice versa.

**Color:** emerald

**Basis:** Padberg & Benz 2021; KMK 2022. Eigene Ableitung: Die Umkehraufgabe ist ein eigenständiges Prüfwerkzeug und verdoppelt den Nutzen eines Zahlfakts.
