# Skill A1.2a

**Skill ID:** A1.2a

**Construct:** A1.2

**Domain:** A

**Title DE:** Rückwärtszählen bis 20

**Title EN:** Counting backward to 20

**Description DE:** Das Kind zählt von einem beliebigen Startpunkt aus abwärts bis in den Bereich der kleinen Zahlen, ohne die Folge zu unterbrechen. Der Wechsel von einer Zahl zur nächstkleineren gelingt sicher.

**Description EN:** The child counts downward from any starting point into the small-number range without breaking the sequence. Moving from one number to the next lower one is done reliably.

**Color:** amber

**Basis:** Wartha 2019; Padberg & Benz 2021. Eigene Ableitung: Rückwärtszählen ist schwieriger als Vorwärtszählen und wird deshalb im kleineren Zahlraum zuerst gesichert.
