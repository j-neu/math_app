# Skill C3.2

**Skill ID:** C3.2

**Construct:** C3.2

**Domain:** C

**Title DE:** Im Hunderterraum in Schritten rechnen

**Title EN:** Calculating step by step in the hundreds range

**Description DE:** Das Kind rechnet im Hunderterraum in mehreren Schritten und nutzt dabei den nächsten vollen Zehner als Zwischenziel. Das Auffüllen auf den Zehner erleichtert auch schwierige Aufgaben.

**Description EN:** The child calculates in the hundreds range in several steps, using the next full ten as an intermediate target. Filling up to a ten also makes difficult tasks easier.

**Color:** emerald

**Basis:** Selter/Spiegel 1997; Schipper 2009. Eigene Ableitung: Schrittweises Rechnen baut auf dem Zählen in Zehnerschritten auf und bleibt anschaulich nachvollziehbar.
