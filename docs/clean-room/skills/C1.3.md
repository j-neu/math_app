# Skill C1.3

**Skill ID:** C1.3

**Construct:** C1.3

**Domain:** C

**Title DE:** Halbierungsaufgaben sicher beherrschen

**Title EN:** Mastering halving facts

**Description DE:** Das Kind beherrscht die Halbierungen im Zahlenraum bis zehn und nutzt sie als Umkehrung der Verdopplungsaufgaben. Zu einer Zahl nennt es zuverlässig ihre Hälfte.

**Description EN:** The child masters halving within ten and uses it as the inverse of doubling facts. For a given number it reliably states its half.

**Color:** emerald

**Basis:** Gaidoschik 2010; KMK 2022. Eigene Ableitung: Halbierungen ergänzen die Verdopplungen zu einem geschlossenen Stützaufgaben-Netz.
