# Skill B1.3

**Skill ID:** B1.3

**Construct:** B1.3

**Domain:** B

**Title DE:** Einen Zehner in Einer tauschen

**Title EN:** Exchanging one ten for ones

**Description DE:** Das Kind tauscht einen Zehner gegen zehn Einer und stellt damit eine Zahl in aufgelöster Form dar. Das Entbündeln gelingt auch dann, wenn die Darstellung der Zahl anschließend neu zusammengesetzt werden muss.

**Description EN:** The child exchanges one ten for ten ones and represents a number in unbundled form. The unbundling also works when the number's representation must then be reassembled.

**Color:** indigo

**Basis:** Schipper 2009; Rahmenlehrplan BE/BB 2023. Eigene Ableitung: Das Rücktauschen eines Zehners ist die Voraussetzung für Borge- und Ergänzungsschritte beim Subtrahieren.
