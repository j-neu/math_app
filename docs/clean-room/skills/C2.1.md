# Skill C2.1

**Skill ID:** C2.1

**Construct:** C2.1

**Domain:** C

**Title DE:** Addieren mit Zehnerübergang über Zerlegen

**Title EN:** Adding across ten by decomposing

**Description DE:** Das Kind löst Additionsaufgaben mit Zehnerübergang, indem es einen Summanden zerlegt und über den Zwischenschritt zur vollen Zehn gelangt. Das Teilschrittverfahren wird dabei bewusst als Weg gewählt.

**Description EN:** The child solves addition tasks with a tens boundary by decomposing one addend and reaching a full ten as an intermediate step. The step-by-step procedure is chosen deliberately.

**Color:** emerald

**Basis:** Gaidoschik 2010; Wartha 2019. Eigene Ableitung: Zerlegungsstrategien ersetzen das zählende Lösen von Übergangsaufgaben im ZR20.
