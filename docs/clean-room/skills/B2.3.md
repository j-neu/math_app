# Skill B2.3

**Skill ID:** B2.3

**Construct:** B2.3

**Domain:** B

**Title DE:** Zahlen in ungewohnter Schreibweise lesen

**Title EN:** Reading numbers in non-standard notation

**Description DE:** Das Kind liest Zahlen in nicht-standardisierter Schreibweise wie „1 Z + 14 E" und erkennt, dass dieselbe Zahl auf verschiedene Weisen gebündelt sein kann. Es überführt solche Darstellungen sicher in die Standardform.

**Description EN:** The child reads numbers written in a non-standard way, such as one ten plus fourteen ones, and recognizes that the same number can be bundled in different ways. It converts such representations reliably into standard form.

**Color:** indigo

**Basis:** Moser Opitz 2013; Padberg & Benz 2021. Eigene Ableitung: Nicht-standardisierte Schreibweisen decken ein rein mechanisches Stellenwertverständnis auf.
