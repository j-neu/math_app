# Skill C4.1

**Skill ID:** C4.1

**Construct:** C4.1

**Domain:** C

**Title DE:** Rechenstrategien bewusst auswählen

**Title EN:** Choosing calculation strategies deliberately

**Description DE:** Das Kind wählt die Rechenstrategie passend zu den gegebenen Zahlen und wechselt zwischen Verfahren, wenn das die Aufgabe erleichtert. Es begründet die gewählte Vorgehensweise.

**Description EN:** The child chooses the calculation strategy to fit the given numbers and switches between procedures when that makes the task easier. It explains the approach it has chosen.

**Color:** emerald

**Basis:** Selter/Spiegel 1997; Gaidoschik 2010. Eigene Ableitung: Flexibles Rechnen zeigt sich in der bewussten, zahlenangepassten Strategiewahl.
