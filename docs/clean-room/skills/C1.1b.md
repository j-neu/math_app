# Skill C1.1b

**Skill ID:** C1.1b

**Construct:** C1.1

**Domain:** C

**Title DE:** Subtraktionsaufgaben bis 10 sicher lösen

**Title EN:** Solving subtraction facts to 10 reliably

**Description DE:** Das Kind ruft Subtraktionsaufgaben bis zehn direkt aus dem Gedächtnis ab und nennt das Ergebnis ohne nachzuzählen. Umkehraufgaben zur Addition werden dabei als Verbindung genutzt.

**Description EN:** The child recalls subtraction facts up to ten directly from memory and states the result without counting back. Inverse tasks to addition are used as a connection.

**Color:** emerald

**Basis:** Gaidoschik 2010; Padberg & Benz 2021. Eigene Ableitung: Subtraktionsfakten werden über die Umkehrung zur Addition mitverfügbar und stabilisieren beide Operationen.
