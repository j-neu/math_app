# Skill A2.3

**Skill ID:** A2.3

**Construct:** A2.3

**Domain:** A

**Title DE:** Mengen vergleichen

**Title EN:** Comparing quantities

**Description DE:** Das Kind vergleicht zwei Mengen und entscheidet zuverlässig, welche größer und welche kleiner ist. Der Vergleich gelingt direkt über die Mengen selbst, ohne vorheriges Abzählen beider Mengen.

**Description EN:** The child compares two quantities and decides reliably which is larger and which is smaller. The comparison works directly on the quantities, without counting both first.

**Color:** amber

**Basis:** Krajewski 2003/2008; KMK 2022. Eigene Ableitung: Mengenvergleich ohne Abzählen belegt ein relationales Mengenverständnis statt reinen Zählens.
